# Bank Management System in C++

A console-based Bank Management System developed in C++ to practise object-oriented programming, file handling, user permissions, and financial transaction management.

## Features

- **Client Management:** List, add, update, delete, and search for clients.
- **Transactions:** Deposit, withdraw, check total balances, transfer money, and view transfer history.
- **User Management:** Add, update, delete, list, and search for users.
- **Access Control:** Control access to application features using user permissions.
- **Login Register:** Keep a record of login activity.
- **Currency Exchange:** List and search currencies, update exchange rates, and calculate currency conversions.
- **File Handling:** Store and retrieve application data using files.

## Object-Oriented Programming

The project applies several OOP concepts, including:

- Classes and objects
- Inheritance
- Encapsulation
- Separation of responsibilities across classes

## Getting Started

### Prerequisites

- Microsoft Visual Studio with a C++ development workload installed.
- A compatible C++ compiler.

### Run the Project

1. Clone or download this repository.
2. Open the solution file (`.sln`) in Visual Studio.
3. Select the appropriate build configuration.
4. Build the solution.
5. Run the application.

> **Note:** The solution filename and required configuration should match the files included in the repository.

## Project Structure

The project is organized into classes responsible for different parts of the application, including client management, user management, transactions, currency exchange, and console screens.
